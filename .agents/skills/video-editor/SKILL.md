# Video editor

Start with the project's brief or the creator's request: subject, audience, target platform, canvas, intended length, source media, and required facts. Do not impose a vlog journey structure on a Reel or a product clip. Preserve the user's chosen style and editing framework.

Use `asset-plan` and `watch` to understand footage. Use `vlog-editor` only for a visit or travel vlog; otherwise write a format-appropriate storyboard and edit decisions directly. Load `voiceover-generator` for new narration in a consented voice (any language supported by the installed model), `video-semantic-search` when searching footage by narration meaning or checking voiceover-to-picture alignment, `broll-curator` for source-linked cutaways, `motion-overlay` for useful graphics, `audio-finisher` for final audio, `color-match` for mismatched sources, `cut-audit` at risky edits, and `render-review` for the actual export. Use `format-repurposer` for another canvas or highlight, `platform-package` for cover art and upload copy, and `style-memory` to record and apply creator corrections across projects. Load only the skill needed for the current step.

Choose the canvas with the intended viewing surface. The local helpers offer wide, vertical, square, and portrait-feed profiles plus explicit dimensions. These are editable starting points; verify current platform rules and interface safe zones when publishing. Keep all work local and free unless the creator explicitly changes that preference. Leave source footage untouched and check the final render's picture, audio, and required-shot coverage before delivery.
